# AGENTS.md

panoma is the local catalog of the projects on a disk. It is a pnpm monorepo with
`apps/web` (Next.js 15, App Router), `apps/cli` (the `panoma` binary), `apps/site` (the
public website), and six packages under `packages/`. The product runs entirely on the
user's machine; nothing leaves it. Only `apps/site` is deployed, and it imports nothing
from the rest of the repository. [deploy.md](docs/deploy.md) explains why.

## Set up

Node.js 22 or newer, and pnpm.

```bash
pnpm install
pnpm --filter "./packages/*" build
pnpm test
```

**The second line is not optional.** Without it, many test files fail with
`Failed to resolve entry for package "@panoma/db"`, which looks like a broken `package.json`
instead of a missing setup step. It is the most common setup trap in this repository.

The other half bites later: packages import one another through `dist`. If you change
`packages/core` and run the `packages/mcp` tests without rebuilding, you are testing the old
code without noticing. Run `pnpm --filter @panoma/core build` first.

Before proposing a change, all three must pass:

```bash
pnpm lint
pnpm -r typecheck
pnpm test
```

## Language follows the reader

This is a project rule, not a preference, and tests enforce the important boundaries.

- **Canonical repository prose**—comments, documentation, commit messages, community
  files—is **English**. Spanish translations live under `translations/` and link back to
  the English source. Identifiers and file names are English too: a file name travels
  through paths and links, which makes it an identifier.
- **A person reading in the browser** gets a bilingual interface through `t(locale, ...)`
  in `apps/web/lib/i18n.ts`. A missing key does not compile.
- **A machine** always reads English. The four machine surfaces are the terminal (`say()` in
  `apps/cli/src/messages.ts`), the MCP server, the `/api/agent/*` HTTP protocol, and the
  untrusted-material wrapper in `packages/core/src/untrusted.ts`. A model does not negotiate
  a language.

Existing Spanish-only decision records under `docs/` predate this rule and are migration
work, not precedent for new or modified prose. Until a record is translated whole, keep
editing it in Spanish: half an English page is worse than a pending translation.

## Guards that will stop you

These are not style rules. Each guard exists because the failure it prevents already
happened without breaking anything visible; that is why there is a test rather than a
convention.

| If you do this | What fails | Why |
|---|---|---|
| A `.test.tsx` file | Vitest does not transform it | Tests use `.ts` and live beside their code. |
| Wrapping app CSS in `@layer` | `styles.test.ts` | Unlayered CSS outranks Tailwind utilities, and the application relies on that order. |
| Writing a color literal in a stylesheet | `styles.test.ts` | Colors live in `app/styles/tokens.css`; the repository once had 122 loose values and seven unrelated reds. |
| Reordering the `globals.css` imports | `styles.test.ts` | The order is the rule in five places; alphabetizing it changes the interface without an error. |
| A loose CLI sentence | `messages.test.ts` | All terminal text goes through `say()` and is English. |
| A bare `fetch(` in the CLI | `catalog-fetch.test.ts` | Use `catalogFetch(...)`, which declares the language header. |
| A Spanish command, or a documented command that does not exist | `commands.test.ts` | The README once taught four dead commands for a full day. |
| Volatile data in the managed `AGENTS.md` block | `agentsmd-stable.test.ts` | It once included the commit count, making the file dirty after every commit. |
| Trusting the `Host` header to mean "this machine" | `guard.test.ts`, `gates.test.ts` | The caller writes it; `curl -H 'Host: localhost'` used to bypass every route that executes work. |

One repository pattern surprises new contributors: **several tests read source code as
text** instead of executing it. This is intentional. It protects invariants that cannot be
executed—an order, an absence, a convention—and lets a decision survive the person who made
it.

## Writing text people read

**Put the number at the end.** Never attach an inflected word to a digit: avoid "1 commits"
and "1 folders." Either the dictionary supplies singular and plural forms, or the sentence
is reordered so the number closes it. This bug has returned nine times and appears only when
n = 1, exactly the case for a new user.

## Tools

There is a linter (`eslint.config.mjs`, flat configuration) and **no formatter**. Do not
reformat files you are not changing, and follow `.editorconfig`. The full suite takes about
a minute; several suites start a real PostgreSQL instance.

## Do not change without asking

`apps/site/`—the landing page and public documentation—has its own release rhythm and design
decisions. If you find a problem there, report it; do not fix it opportunistically.
